사용 가능

인스타 연속 사진

한 장의 사진을 이어지는 여러 장으로 나누고 워터마크를 넣습니다. 미리보기를 확인한 뒤 JPEG 또는 ZIP으로 저장하세요.

도구 열기 → 사용 가능

파일명 내보내기

사진에 백색·흑색 파일명 워터마크를 넣고 위치를 지정해 파일당 5MB 이하로 내보냅니다.

도구 열기 → 사용 가능

사진 메타데이터 추출기

사진 파일의 카메라, 렌즈, ISO, 셔터스피드, 조리개 정보를 브라우저에서 바로 확인하고 복사합니다.

도구 열기 → 사용 가능

셔터횟수 보기

카메라 원본 사진에서 셔터·촬영 카운터를 확인합니다. 서버 업로드 없이 브라우저에서 분석하며, 모델에 따라 지원이 다릅니다.

도구 열기 → 사용 가능

노출·ND 계산기

조리개와 ISO를 바꿀 때 같은 노출의 셔터스피드를 계산하고, ND 필터를 적용한 촬영 시간을 타이머로 확인합니다.

도구 열기 → 베타

RAW 별점·색상 레이블 자동화

선택한 RAW 파일의 XMP 별점과 한국어·영어 Lightroom 색상 레이블을 폴더 단위로 일괄 변경합니다.
