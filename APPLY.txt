Matchcamera Panasonic 네이버 브랜드스토어 이미지+가격 v17

대상
====
https://brand.naver.com/panasonic/category/d1638682756a48b4a157b156ed0f2ca8?cp=1

기능
====
- 카테고리 페이지 자동 순회
- Panasonic 바디/렌즈 상품 상세 페이지 확인
- 공식 가격 자동 추출
- 대표 제품사진 자동 추출
- Matchcamera Panasonic 제품 DB와 안전 매칭
- 제품명 매칭이 애매하면 DB를 수정하지 않고 report에만 기록

가격 규칙
=========
1. 할인 전 정상가 / 소비자가 / 정가가 보이면 우선
2. 정상가가 따로 없으면 공식 브랜드스토어 현재 표시 판매가 사용
3. 가격 유형을 JSON에 구분해서 저장
4. 병행수입/해외가격은 사용하지 않음

저장
====
가격:
public/data/korea-prices.json

이미지:
public/assets/images/products/panasonic/
public/data/product-images.json

전체 추출/매칭 리포트:
public/data/panasonic-naver-extracted.json

실행
====
먼저:
TEST_PANASONIC_NAVER_IMAGES_PRICES.bat

첫 5개 결과의 제품명/이미지/가격이 정확한지 확인.

정상이라면:
UPDATE_ALL_PANASONIC_NAVER_IMAGES_PRICES.bat

주의
====
- 이 ZIP은 현재의 korea-prices.json / product-images.json을 덮어쓰지 않습니다.
  실행 시 현재 로컬 데이터를 읽어 필요한 Panasonic 항목만 갱신합니다.
- CAPTCHA/로그인/접근제어를 우회하지 않습니다.
- 네이버가 자동 브라우저에 추가 확인 화면을 띄우면 전체 실행을 중지하고
  visible 모드 테스트 창에서 정상 접근되는지 먼저 확인하세요.
