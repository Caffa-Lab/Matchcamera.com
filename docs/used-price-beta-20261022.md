# 중고가 베타와 메인 경로 변경 · 2026-10-22

## 공개 경로

- `/`: 기존 프로그램 목록. 개별 `/program/.../` 도구 주소는 유지한다.
- `/home/`: 기존 카메라 홈페이지. 배너와 대표 제품 설정은 기존 `home-config.json`을 계속 사용한다.
- `/program`, `/program/`, `/program/index.html`: 쿼리를 유지하며 `/`로 308 이동한다.
- `/betatest/`: 국내 중고 판매 호가 베타. 초기 버전은 `noindex`이며 사이트맵에서는 제외한다.

## CamPrice 분석과 이번 구현 범위

CamPrice는 공개 매물을 수집하고 모델·구성별로 연결한 뒤 중복·묶음·이상치를 분리해 판매 중 호가와 판매 완료 표시 가격을 분석한다고 설명한다. 판매 완료 표시는 실제 최종 결제 금액을 보장하지 않는다.

- 소개: <https://camprice.kr/about>
- 공개 도구 안내: <https://camprice.kr/llms.txt>
- 이용 조건: <https://camprice.kr/terms>

공개 조회 도구는 존재하지만, 공개 도구 결과를 모아 재배포하거나 상업적으로 이용하는 것은 별도 협의 대상이다. 이번 베타는 이 API, 통계 및 매물 데이터를 사용하지 않는다. HTML로 바꾸어 해당 통계를 복제하는 방식도 사용하지 않는다.

## 데이터 출처와 의미

초기 자료는 아래 판매점의 개별 공개 상품 HTML에서 확인했다. JSON-LD 가격과 화면의 판매가가 일치하고, 중고 단품과 제품 세대·마운트를 직접 검토한 자료만 내부 제품 ID에 연결했다.

- 캐논스토어 서울역점: <https://canon-store.com/>
- 국민카메라: <https://kookmincamera.co.kr/>

2026-10-22 기준 판매 중으로 표시된 **21개 상품, 20개 모델**을 공개한다. 품절로 확인한 **16개 상품은 종료·품절 기록으로 별도 공개**하며, 판매 중 최저·최고·중앙값 계산에 합치지 않는다. 필수 유료 옵션이 붙어 표시 금액만으로 단품을 살 수 없는 상품은 제외했다.

가격을 확인할 수 없는 상품은 판매 상태와 관계없이 공개 목록에서 모두 제외한다. 현재 **가격 확인 출처 2개, 상품 37개, 모델 34개, 가격 관측 37건**을 제공한다. 가격 비공개 상품의 상태 기록과 연결된 관측 기록, 공개 상품이 남지 않은 출처도 데이터에서 제거한다.

`public/data/used-prices.json`은 확인 시점의 스냅샷이며 실시간 전체 시장 데이터가 아니다. 판매처의 상품 이미지와 상세 설명을 복제하지 않는다. 사진은 기존 Matchcamera 제품 이미지를 사용하며, 상품 페이지 링크와 짧은 상태 사실만 제공한다. 파일의 `evidence.contentSha256`은 확인에 사용한 HTML의 해시다.

`in-stock`는 판매처가 페이지에서 판매 중으로 표시한 상태다. 실제 물리적 재고 수량을 보장하지 않으며 UI에서도 판매처 표기임을 밝힌다. 재고 수량을 관리하지 않는 상점의 `stock_number=0`을 품절로 오해하지 않도록 주의한다. 명시적 품절 표기는 가격 계산에서 제외한다.

`sold-out`의 `completionStatus`는 `sold`와 `out-of-stock`을 구분한다. 품절 아이콘이나 OutOfStock만으로 실제 판매 완료를 단정하지 않는다. `sold`에는 상품 상세의 명시적 판매완료 근거인 `completionEvidence`가 필요하다. 완료 후 금액을 숨기는 판매처의 상품도 공개 목록에서 제외하며, 가격을 0원이나 임의 금액으로 채우지 않는다. 수치 가격을 확인한 판매 중·품절·판매완료 상품은 유지한다. 확인일은 실제 거래일이 아니며 종료 상품의 표시가는 실제 결제 금액을 보장하지 않는다.

## 이미지와 가격 그래프

제품 카드와 상세 이미지에 고정 영역, 최소 크기 해제, `object-fit: contain`, 넘침 제한을 적용했다. 긴 망원렌즈와 세로 이미지도 카드 밖으로 나오지 않도록 한다.

`observations`는 상품 ID·출처 URL·실제 확인일·당시 가격·당시 판매 상태를 기록한다. 초기 가격 기록은 **2026-10-22 하루**다. 과거 등록일·사진 파일 날짜를 가격 확인일로 대체하거나, 현재 가격으로 과거 추이를 만들지 않는다. 그래프는 최근 90일 내 실제 관측일의 최저·최고 범위를 판매 중/종료·품절로 나누어 표시한다. 3개 이상인 날만 중앙값을 표시하고, 실제 연속된 관측일의 중앙값만 연결한다. 하루치 자료는 점으로 표시하며 없는 날짜의 값을 보간하지 않는다.

가격 비공개 상품은 공개 목록과 관측 기록에서 모두 제외하므로 그래프에도 포함하지 않는다. 날짜별 정확한 값과 표본 수는 펼칠 수 있는 표로 제공한다. 가격이 확인된 종료 기록만 있거나 최근 확인일이 지난 제품도 검색에서 찾을 수 있고, 전체/판매 중/판매 완료·품절 필터를 제공한다.

## 집계 기준

- 원 단위의 양의 정수 판매 호가만 허용한다. 가격 비공개·누락·0원·그 밖의 유효하지 않은 가격은 상품과 연결된 관측 기록에서 모두 제외한다. 신품가·매입가·추정가와 합치지 않는다.
- 중고 전용 `kind: used-sale`, 검토한 내부 `productId`, 단품 구성, 출처와 확인일이 필요하다.
- 원본 카탈로그와 공식 가격 파일은 수정하지 않는다. 견적 합계도 기존 공식 가격 기준이다.
- 같은 상품 URL을 중복 표본으로 세지 않는다. 추적 파라미터와 URL 조각은 제거한다.
- 한국 날짜 기준 7일 이내이고 판매 중인 상품만 최근 최저·최고 호가 계산에 사용한다.
- 재고 미확인 자료는 별도 표시하고, 7일이 지난 자료는 이전 기록으로 구분한다.
- 유효 표본 3개 이상일 때만 중앙값을 표시한다. 현재 초기 모델은 1~2개이므로 중앙값을 표시하지 않는다.
- 판매점 등급, 컷수, 보증, 배송비 차이를 감정하거나 보정하지 않는다.
- 자료가 없는 제품의 가격을 0원이나 추정값으로 채우지 않는다.

## 유지 관리

상품 URL과 내부 모델 매핑은 사람이 검토한 목록으로 한정한다. 새로운 상품을 추가할 때 세대·마운트·단품/키트·신품/중고·필수 옵션을 다시 확인한다.

`scripts/refresh_used_prices.py`는 지원하는 두 판매점의 검토된 공개 상품 HTML만 재확인하는 관리 도구다. 외부 가격 API를 호출하거나 목록을 무제한 탐색하지 않는다. 기본 실행은 변경 미리보기이며 `--write`를 명시해야 데이터 파일을 저장한다. 성공한 경우 실제 확인 날짜의 가격 관측 기록을 추가하고, 같은 날의 재확인은 그날의 기록만 갱신한다. 과거 날짜는 보존하고 누락 날짜는 채우지 않는다. 네트워크 오류나 상품명·가격 검증 실패 시 예전 확인일을 오늘로 갱신하거나 관측 기록을 만들지 않는다. 별도 판매처의 완료 기록은 원문을 직접 검토해 갱신하며, 지원하지 않는 판매처를 이 파서로 추정 처리하지 않는다. 현재 자동 실행 일정은 등록하지 않았다.

```powershell
python -X utf8 scripts/refresh_used_prices.py
python -X utf8 scripts/refresh_used_prices.py --write
node scripts/test_used_prices.mjs
node scripts/test_used_price_ui.mjs
python -X utf8 scripts/test_used_price_collection.py
```

검증 후 저장소에 반영하고 기존 Cloudflare 배포 절차를 사용한다. 판매점 공개 방식이나 이용 조건이 바뀌면 수집을 중단하고 파서를 검토한다.
