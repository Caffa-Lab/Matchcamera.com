# BETA 실험실 · 2026-11-07

프로그램 홈(/)에 새 기능 9개의 직접 실행 카드를 공개하고 각 카드에 BETA를 표시했다. 기존 장비 프레임 대표 영역과 상단 메뉴 순서는 유지했다. 설명 모음 /beta/는 noindex,follow로 유지하며 실제 실행 페이지 /program/calculators/, /program/kit/, /program/photo-privacy/는 index,follow와 사이트맵에 등록했다. 검색엔진에 노출되는 시점은 별개다. 기존 중고가 /betatest/와 개인 간 중고거래 수집 보류 상태는 유지한다.

## 제공 기능

1. `/builder/#budgetRecommendations`: 기록 가격과 근거가 있으며 현재 판매로 표시된 공개 미러리스 바디 + 렌즈의 직접 장착 조합을 예산 안에서 찾는다. 제조사·환산 화각 필터, 가격 유형·출처·날짜, 기존 견적 적용을 제공한다. 조건부/어댑터 조합·가격 미확인 제품·DSLR은 제외한다. 바디 가격 비중 60%와 예산 활용도로 정렬하며 성능 순위를 주장하지 않는다. 적용 시 기존 구성과 액세서리 선택을 교체하므로 화면에서 안내한다.
2. `/program/kit/`: 실제 제품과 수동 입력 장비, 수량·무게·챙김 상태를 같은 브라우저에 저장한다. 무게 미확인 개수는 합계와 구분한다. JSON 백업/복원과 장비 CSV 저장을 제공하며 CSV 수식 실행·백업 스키마/이미지 경로를 검증한다.
3. `/program/kit/#checklist`: 기본 촬영 준비 항목과 사용자 항목을 추가·삭제하고 완료 상태를 저장한다. 백업에 함께 포함한다. 타 기기 자동 동기화는 제공하지 않는다.
4. `/program/calculators/#dof`: 얇은 렌즈 모형과 공개한 허용 착란원 가정으로 심도·과초점거리를 계산한다. 무한대와 잘못된 입력을 구분한다.
5. `/program/calculators/#fov`: 센서 가로·세로와 실제 초점거리로 가로/세로 화각·대각선 기준 35mm 환산 초점거리를 계산한다.
6. `/program/calculators/#storage`: 십진 GB/MB와 Mb/s, 사용자 지정 사용 가능 비율로 사진 장수 및 영상 시간을 각각 계산한다. 실제 포맷·가변 비트레이트·혼합 저장과 차이가 있을 수 있다.
7. `/program/calculators/#timelapse`: 프레임 수와 시작 간격으로 첫 촬영 시작부터 마지막 노출 종료까지의 시간을 계산한다. 노출이 간격을 초과하면 오류를 표시한다.
8. `/program/calculators/#print`: 원본 픽셀과 PPI로 cm·인치, 희망 가로에서의 실제 픽셀 밀도를 계산한다. PPI와 프린터 DPI를 구분하며 업스케일 결과의 품질을 보장하지 않는다.
9. `/program/photo-privacy/`: JPEG·PNG·WebP를 브라우저에서 방향 보정해 새 픽셀 이미지로 인코딩한다. 원본 EXIF·GPS·IPTC·XMP·주석을 복사하지 않으며 출력 컨테이너도 검사한다. 출력 이름은 일반 이름으로 대체하며 개별/ZIP 저장을 제공한다. 원본은 수정하지 않는다. 최대10장/장당50MB/합계200MB/1억화소. JPEG·WebP의 손실, ICC/색 표현 변화, 애니메이션의 정지 이미지 변환을 화면에 알린다. 얼굴·표지 등 픽셀 속 정보는 지우지 않는다.

계산기는 각 화면에 공식 기술자료 링크와 모형/단위/가정을 제시한다. 장비 정보는 기존 제품 DB를 사용하며 이번 변경은 한국 공식 가격 재검증이나 카탈로그 신규 제품 추가 작업을 포함하지 않는다. 추천 가격은 실시간 최저가·판매 재고를 의미하지 않는다.

## 데이터와 운영

사진과 장비 보관함/체크리스트는 서버로 업로드하지 않는다. 기존 방문 통계에는 고정 페이지 종류(beta,calculators,kit,photo_privacy)만 추가하며 사진명·장비 선택·계산값·체크리스트를 보내지 않는다. 기존 방문 식별값 만료·측정 거부 기준은 유지한다. 개인정보처리방침에 사진 도구와 로컬 장비 저장을 반영했다.

새 비밀키·회원가입·유료 외부 API·새 저장소 바인딩 없이 기존 Worker 정적 자산 배포를 사용한다. 내 장비는 localStorage의 `matchcamera.kit.v1`에 저장된다. 사이트 데이터를 지우기 전에 JSON 백업이 필요하며 초기화·덮어쓰기는 화면 확인을 받는다.

## 검증

`test_budget_recommendations.mjs`, `test_photo_calculators.mjs`, `test_kit_planner.mjs`, `test_photo_privacy.mjs`, `test_beta_integration.mjs`를 두 GitHub Actions 검증에 추가했다. 단위·실제 카탈로그 검사와 함께 브라우저에서 추천→견적 반영, 계산 오류·단위, 장비 저장, 사진 사본 생성·다운로드를 확인한다. 개인정보 도구는 EXIF orientation6을 포함한 테스트 JPEG를 실제 브라우저로 내보내고, 사본의 방향 보정 및 EXIF 제거를 별도로 확인한다. 운영 데이터에 테스트 장비·개인 방문자 기록을 넣지 않는다.
