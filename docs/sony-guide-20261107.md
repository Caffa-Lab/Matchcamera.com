# 소니 설정 가이드 · 2026-11-07

`/sony/`에 소니 카메라 설정·촬영 팁을 제공한다. 사용자의 요청대로 상단 공통 메뉴에는 링크나 메뉴 항목을 추가하지 않았다. 직접 주소와 사이트맵으로 접근할 수 있다.

## 범위와 근거

- 설정 53개: 화질·색, AF·피사체, ISO·노출, 셔터·손떨림, 영상·오디오, 버튼·저장, 문제 해결.
- 매치카메라의 상황별 시작 예시 6개: 낮 인물, 일상·거리, 움직임, 풍경, 삼각대 야경, 간단한 영상. 소니 공식 공통 프리셋으로 표현하지 않는다.
- 기종별 공식 도움말 6개: α7 IV, α7R V, α6700, α7C II, α1 II, α7 V. α7 V는 `/ilc/2540/`이며 FX2의 `/2530/`과 구분했다.
- 공식 근거는 Sony Help Guide·Sony KR·Sony Digital Imaging의 실제 확인한 문서다. 각 설정의 기능 명칭·확인 순서·활용 팁·기종별 제한·출처와 기준 모델을 표시했다. 메뉴 번호나 단일 공통 메뉴 경로는 지정하지 않는다.
- α 렌즈 교환식 중심의 가이드다. 모든 Sony 카메라가 같은 RAW/AF/영상/셔터/백업 기능을 지원한다는 뜻이 아니다. 최신 펌웨어 여부나 기종별 모든 메뉴를 보증하지 않는다.

특히 ISO AUTO 최소 속도의 P/A 조건과 ISO 상한 이후 저속 가능성, 전자/무음 셔터의 모델별 플래시·BULB 제한, 손떨림 보정과 피사체 움직임, LUT 표시·파일 삽입·색 적용의 차이, 온도 '고' 설정의 실제 주의사항, 듀얼 카드 동시 기록과 자동 전환의 차이를 구분했다. α1 II의 자동 인식 대상을 α7R V의 공통 기능으로 설명하지 않으며 초점 브래킷·픽셀 시프트·사전 캡처도 각각 기준 기종을 명시한다.

## 구현

검토한 콘텐츠는 `public/data/sony-guide.json`에서 관리한다. `node scripts/build_sony_guide.mjs`가 HTML의 지정 영역만 생성하므로 내용과 공식 출처를 JavaScript 없이 읽을 수 있다. `--check`는 데이터와 HTML이 일치하는지 검증한다.

`sony-guide.js`는 설정/증상 검색, 분야 선택, 펼치기·접기, 기종별 도움말 선택, 설정별 직접 링크 열기와 복사를 제공한다. 복사 링크에는 검색 파라미터를 포함하지 않는다. 카메라 설정이나 사용자 사진을 읽거나 변경하지 않는다.

기존 방문 집계에는 고정 페이지 코드 `sony`만 추가했다. 검색어·선택 기종·설정 클릭·사진 정보는 보내지 않는다. 기존 측정 거부와 만료 기준을 유지한다.

## 검증

- 각 주제를 공식 문서에서 확인하고 기종·조건을 교차 검토했다.
- `test_sony_guide.mjs`: 콘텐츠/공식 출처/HTML 일치, 안전한 출력, 검색·분야·직접 링크·복사, 상단 메뉴 미추가, 기존 방문 집계 연결.
- 모바일·좁은 화면에서 가로 넘침과 메뉴/상세 열기, 공식 모델 링크를 확인한다.
- GitHub의 두 검증 워크플로에 가이드 생성 상태와 테스트를 포함했다.
